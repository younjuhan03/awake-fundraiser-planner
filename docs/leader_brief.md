# AWAKE 리더용 요약: 사전주문 이후 얼마를 더 만들 것인가

**관측:** 2026년 봄 사전주문은 29건, 104개, $375다. 실제 생산량·잔여량·현장 판매량·비용 기록은 없다.

**계산:** S25 비용 $190을 구매 수량 108개로 나누면 개당 약 $1.76다. 새 행사에 적용하는 것은 가정이다. 현장 가격을 $3.50로 가정하면 추가 생산분의 약 50.3%가 팔려야 추가 비용을 회수한다.

104개에 10% 여유분을 더하면 올림하여 115개다. 추가분은 11개다. 추가분 판매율이 0%이면 사전주문 수량만 만드는 것보다 약 $19.35 손해, 50%이면 약 $0.10 손해, 100%이면 약 $19.15 이익이다. 판매 예측이 아닌 조건별 계산이다.

## 사용 순서

1. `exports/fundraiser_planner.xlsx`의 Planner에서 이번 행사의 확정 사전주문 수량과 금액을 입력한다.
2. 현재 원가, 여유분, 현장 가격과 판매율 가정을 바꾼다. 기존 개당 원가에 포함된 소모품비를 고정비로 중복 입력하지 않는다.
3. 0%·선택한 비율·100% 판매율을 비교한다. 비용 증가·주문 취소까지 포함한 최악·최선은 아니다.
4. 큰 주문의 수령 계획을 확인한다. S26의 한 주문이 전체 수량의 26.9%였다.
5. 행사 후 실제 생산량, 수령·판매량, 잔여량, 영수증 총액과 준비 시간을 기록하고 계획과 비교한다.

## 해석

- 사용자가 정한 여유분을 평가하며 최적 수량이나 가격을 찾아주지는 않는다.
- 기존 주문 금액은 관측값이다. 확인되지 않은 가격 차이를 임의로 설명하지 않는다.
- S26 순이익 $101–$294는 가정에 따른 범위이며 실제 순이익이 아니다.
- F24 순이익은 거래 기반 $234.54를 사용한다. 메모와 차이 $26.59는 미해결이다.
- 폐기 감소율을 입증할 기록은 없다. 운영 경험과 분석 도구 검증 성과를 구분한다.
